核心功能解析

  1. 多协议代理支持：Quantumult X支持HTTP、HTTPS、SOCKS5等多种代理协议，用户可以根据不同的网络环境选择最适合的协议类型。这种灵活性确保了在各种网络条件下的稳定连接。

绿色问号：网络健康的晴雨表

绿色问号功能是Quantumult X中一个极具创新性的设计。它通过直观的视觉反馈，让用户能够快速判断网络请求的状态。这个看似简单的功能背后，其实蕴含着复杂的网络诊断机制。

绿色问号的工作原理

当Quantumult X处理一个网络请求时，它会从多个维度评估请求的健康状况： - 连接建立时间 - 数据传输速度 - 响应状态码 - 内容完整性验证

只有当所有这些指标都达到预设的标准时，才会显示绿色问号标识。这种全方位的检测确保了反馈的准确性。

状态标识的完整解读

  1. 绿色问号：表示请求完全正常，所有指标均符合预期标准。这是最理想的状态。

  2. 黄色问号：提示请求存在轻微问题，可能是响应时间略长或部分内容加载不完全。这种情况下网络功能基本正常，但可能需要关注。

  3. 红色问号：表明请求遇到严重问题，可能是连接失败、超时或内容验证不通过。此时用户应当检查网络设置或代理配置。

第二步：基础配置

  1. 服务器添加：进入"代理"选项卡，点击右上角的"+"号，根据服务商提供的信息填写服务器地址、端口、认证信息等。Quantumult X支持手动输入和二维码扫描两种添加方式。

  3. 策略组设置：这是Quantumult X的高级功能，允许用户根据不同的使用场景自动切换代理策略。例如，可以设置国内直连、国外走代理等规则。

第三步：规则配置的艺术

Quantumult X的规则系统是其最强大的功能之一。合理的规则配置可以显著提升网络使用体验。

  1. 基础规则模板：初学者可以从内置的规则模板开始，这些模板已经包含了常见国内外网站的分流规则。

  2. 自定义规则：进阶用户可以添加针对特定域名或IP的自定义规则。规则支持通配符匹配，如*.google.com可以匹配所有Google子域名。

  3. 规则优先级：Quantumult X按照从上到下的顺序匹配规则，因此应将更具体的规则放在前面，通用规则放在后面。

第四步：启用并理解绿色问号

在"设置"→"高级"中，确保"请求状态标识"选项已开启。启用后，用户可以在请求日志中看到每个请求旁边的状态标识。

FAQ

Shadowsocks 密码泄露后应如何应对？
立即更改服务端密码与相应的端口，检查服务器是否存在异常连接或 root 活动，查看日志并封禁可疑 IP。若使用多人共享节点，建议为每个用户单独分配独立端口与密码以降低风险传播。
Surfboard 能否同步 Quantumult X 的规则？
Surfboard 的规则语法与 Quantumult X 相似，但并非完全兼容。部分策略组或脚本需手动修改格式方能正常使用，因此不建议直接复制，最好通过转换工具处理。
Clash 订阅被墙或无法下载如何绕过？
若订阅源被直接屏蔽，可尝试先在境外服务器上用代理代理获取订阅并通过中转服务器公开一个新的链接；或者使用 HTTPS 与 CDN 中转、或将订阅以文件形式托管在不易被封的云存储上。
Surfboard 支持规则分流功能吗？
支持。Surfboard 可通过规则文件和策略组将不同类型流量分配到指定节点。保证网页浏览、视频和游戏走最优线路，提高访问速度和整体网络稳定性。
VLESS + XTLS 模式在移动网络下表现如何？
XTLS 模式减少握手次数和加密开销，适合高延迟或不稳定移动网络。结合策略组和多出口节点，可提高访问速度和连接稳定性，保证用户体验流畅。
PassWall2 的延迟测试如何影响策略组选择？
PassWall2 会根据节点延迟结果更新策略组的优先节点，自动选择延迟最低的节点处理流量。这样可以优化访问速度，提高网页浏览、视频和游戏体验的稳定性。
Clash Premium 与普通版本有何不同？
Clash Premium 是 Clash 的增强版，增加了 TUN 模式、脚本功能、流量统计与规则订阅等高级特性。它更适合有复杂分流需求的用户，尤其是需要对系统级代理进行全局控制的场景。
Hysteria2 多路复用如何优化高频短连接？
多路复用允许多个短连接共享同一通道，减少握手次数和加密开销。适合游戏和即时通讯等高频短连接场景，提高吞吐量和连接稳定性，保证流量快速传输。
如何把 Clash 规则与本地 hosts 文件结合使用？
可在 Clash 的 rules 中优先设置域名直连规则，并在系统 hosts 中添加常用站点的固定解析以加速 DNS 解析。注意 hosts 优先级高于 DNS，因此修改 hosts 需谨慎以避免与真实解析冲突。
Mellow TUN 模式如何拦截全局流量？
TUN 模式会拦截系统 IP 层的所有流量，实现全局代理。相比 SOCKS5 只影响部分应用，TUN 可以覆盖游戏、视频和浏览器等所有流量，提高科学上网体验的全面性。

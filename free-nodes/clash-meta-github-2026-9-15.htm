一、准备工作：确保一切就绪

在开始配置之前，我们需要做好充分的准备工作，以确保后续步骤顺利进行。

1.1 检查网络连接

首先，确保您的小米路由器已正确连接互联网。可以通过以下步骤验证：
- 使用手机或电脑连接小米路由器的Wi-Fi信号
- 打开浏览器，尝试访问任意网站（如百度、谷歌）
- 如果能够正常访问，说明网络连接正常

1.2 获取科学上网服务

科学上网需要依赖特定的服务提供商，您需要提前购买合适的套餐。目前市面上常见的科学上网协议包括：
- VPN：传统虚拟专用网络，如PPTP、L2TP/IPSec、OpenVPN等
- SS/SSR：Shadowsocks及其衍生版本，以高效稳定著称
- V2Ray：新一代代理协议，具有更强的抗干扰能力

建议选择信誉良好的服务商，并获取相应的服务器地址、端口、账号密码等信息。

2.1 连接路由器

使用电脑或手机连接小米路由器的Wi-Fi网络。默认情况下，Wi-Fi名称和密码可以在路由器底部标签上找到。

- 用户名：admin
- 密码：admin

如果您之前修改过密码，请使用新密码登录。如果忘记密码，可能需要重置路由器。

三、配置科学上网插件

小米路由器的强大之处在于其丰富的插件支持，我们可以通过安装科学上网插件来实现全局代理。

3.1 进入应用中心

登录管理界面后，在左侧菜单中找到"应用中心"选项并点击进入。这里汇集了各种实用的路由器插件。

3.2 安装科学上网插件

在应用中心中搜索"科学上网"或"VPN"相关插件。常见的选择包括：
- 小米官方VPN插件

- OpenWRT兼容插件（适用于高级用户）

找到合适的插件后，点击"安装"按钮，等待安装完成。

四、详细配置指南

根据您选择的不同科学上网协议，配置方法也有所差异。下面我们分别介绍VPN和SSR的配置方法。

4.1 VPN配置步骤

  1. 返回管理界面，找到已安装的科学上网插件
  2. 选择"VPN"选项卡

  3. 填写以下信息：

    • 服务器地址：您的VPN服务商提供的服务器IP或域名
    • 账户名：VPN登录用户名
    • 密码：VPN登录密码
    • 协议类型：根据服务商建议选择（PPTP/L2TP/OpenVPN等）

  4. 点击"保存"按钮应用设置

4.2 SSR配置步骤

  1. 在科学上网插件中选择"SSR"配置

  2. 填写以下详细信息：

    • 服务器：SSR服务器的IP地址或域名
    • 端口：服务商提供的连接端口（通常为4-5位数字）
    • 密码：SSR连接密码
    • 加密方式：如AES-256-CFB等
    • 协议：可选origin/authaes128md5等
    • 混淆：可选plain/http_simple等

  3. 保存配置并启用服务

FAQ

如何给 Clash 添加自定义域名白名单以提升访问体验？
在 rules 中添加 `DOMAIN-SUFFIX,example.com,DIRECT` 或 `DOMAIN-KEYWORD,example,DIRECT` 条目，将常用且可靠的站点设为直连，可减少代理绕行延迟并避免因代理造成的登录/验证问题。
Vmess 是什么协议？
Vmess 是 V2Ray 的核心传输协议之一，提供高效的加密通信。它在客户端与服务器之间建立安全通道，支持多种传输方式，如 TCP、WebSocket 和 gRPC 等。由于其加密特性，Vmess 常用于绕过网络限制与防火墙检测。
Surfboard 的配置文件可以与 Clash 通用吗？
Surfboard 基于 Clash 核心，因此支持大部分 YAML 配置文件，但部分字段如 rule-provider、external-controller 等可能不兼容。建议使用订阅转换工具将 Clash 文件转换为 Surfboard 兼容格式导入。
Nekoray 节点订阅自动更新如何设置？
用户可添加订阅 URL，Nekoray 会定期自动下载并更新节点列表。保持节点最新可减少手动维护，提高节点可用性和网络连接稳定性，确保科学上网体验顺畅。
VMess AEAD 加密在高封锁网络的作用？
AEAD 加密可防止数据篡改和流量特征泄露，降低被封锁和 DPI 检测风险。保证节点长期可用，提高数据传输安全性和访问可靠性，优化用户科学上网体验。
Potatso Lite 的节点导入方式有哪些？
Potatso Lite 支持通过手动添加节点信息或扫描二维码导入节点。虽然不支持自动订阅更新，但对轻量用户来说，手动方式足够使用，方便在 iOS 设备上管理节点。
V2Ray 服务器启动后提示端口被占用，该如何处理？
先用 netstat 或 ss 工具查看占用该端口的进程（例如 `ss -ltnp`），确认是旧进程或其他服务占用。停止占用进程或修改 V2Ray 配置端口，然后重启服务并检查防火墙规则是否开放了新端口。
VLESS 是否比 Trojan 更稳定？
两者都非常稳定，但 VLESS 在多平台兼容性上略优，而 Trojan 在 HTTPS 伪装和 TLS 安全性上更强。选择取决于服务器环境与具体需求，两者皆为高性能协议。
Clash 支持多配置文件加载吗？
Clash 支持多配置切换，用户可在图形界面中导入多个 YAML 文件，并通过选择不同配置快速切换使用场景。例如家用模式、移动模式或公司网络模式。
Netch 的规则代理与全局代理如何选择？
全局代理会将所有流量通过节点转发，而规则代理只针对指定 IP、端口或应用。用户可根据需求选择，以优化带宽利用和流量分流，确保不同应用的最佳体验。
